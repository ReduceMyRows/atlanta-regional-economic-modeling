# Atlanta Regional Economic Study

**Industry Structure, Employment Growth, and Regional Forecasting**

An independent applied economics research project examining regional employment trends, industry composition, and economic forecasting in metropolitan Atlanta.

## Planned Methods

* Regional shift-share analysis
* Industry employment analysis
* Econometric forecasting
* Scenario and sensitivity analysis

## Data Sources

* U.S. Bureau of Labor Statistics
* U.S. Bureau of Economic Analysis
* U.S. Census Bureau

## Software

R, Git and Powershell for repo.
